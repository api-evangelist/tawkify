# Tawkify

> Tawkify is a US personalized matchmaking service that pairs paying clients with a trained human
> matchmaker rather than offering a self-service dating app. Founded in 2012 and headquartered in
> San Francisco, it screens and hand-selects introductions, arranges curated first dates, and
> collects structured feedback after each match.

## About this file

This llms.txt was GENERATED by API Evangelist from the public Tawkify website and this repository's
artifacts. Tawkify does not serve an llms.txt of its own (https://tawkify.com/llms.txt returned 404
on 2026-08-29). It is a third-party description, not a document published by Tawkify.

## API surface

Tawkify publishes **no public API**. There is no developer portal, no API reference, no SDK, no
webhook surface, and no machine-readable contract (OpenAPI, AsyncAPI, GraphQL SDL, Postman
collection or JSON Schema) at any public URL. Contract discovery on 2026-08-29 probed both Tawkify
hosts for OpenAPI, Swagger, GraphQL introspection, MCP `tools/list`, A2A agent cards and every
`/.well-known/*` document; all returned 404. `api.tawkify.com`, `developer.tawkify.com` and
`docs.tawkify.com` do not resolve. The customer application at `app.tawkify.com` is a private
Next.js app whose robots.txt disallows all crawling. Agents should not expect a callable Tawkify
endpoint.
